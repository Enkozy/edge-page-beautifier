Edge 页面美化 · 液态玻璃 v1.2.0
==========================================

一个给 Edge 用的必应搜索页 / 新标签页美化扩展。
项目主页：https://github.com/Enkozy/edge-page-beautifier
问题反馈：https://github.com/Enkozy/edge-page-beautifier/issues

安装（约 1 分钟）
----------------
1. 先把整个压缩包解压到一个固定位置，例如：
   D:\Extensions\edge-page-beautifier-v1.2.0
   注意：不要直接在压缩包里打开；装好以后也不要删掉这个文件夹。

2. 打开 Edge，地址栏输入：
   edge://extensions/

3. 打开左下角的「开发人员模式」。

4. 点「加载解压缩的扩展」，选择 edge-page-beautifier-v1.2.0 文件夹。
   选中的文件夹里应该能直接看到 manifest.json。

5. 打开 https://cn.bing.com/ 搜索，或按 Ctrl+T 打开新标签页。

如果 Edge 提示「请关闭开发人员模式扩展」：
点「保留」或「启用」，不要点「移除」。
重启 Edge 后如果被禁用，回扩展页重新打开即可。

使用
----
- 必应页面右下角的水滴：打开设置面板
- Alt + G：打开 / 收起面板
- Alt + Shift + G：一键开关效果
- 工具栏的扩展图标：背景裁剪 / 更多设置
- 新标签页底部的「恢复常用网站」：恢复浏览器里最常访问的网站
- 新标签页的「+ 添加快捷」：手动添加网站；悬停图标右上角的 × 删除

注意
----
- 这个版本会接管 Edge 的新标签页（不包含原版新闻流和天气）。
  如果不想要：删除 manifest.json 里的 "chrome_url_overrides" 整段，
  然后在扩展页点「重新加载」，必应搜索页效果不受影响。
- 需要 Edge 105 或更高版本。
- 「恢复常用网站」需要允许读取你的常用网站（topSites），只在本机使用，不会上传。
- 本扩展不是微软官方产品；Bing、Edge 是 Microsoft 的商标。

更多说明和常见问题见 README.md。
